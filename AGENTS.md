# Smash & Dash — how to reach the running game

Agent tools (map and decisions: `docs/agent-map.md`, `toolsmith/decisions.md`; the engine's: `external/ska/AGENTS.md`). Use them before writing an ad-hoc script, a sleep or asking the human to play. `tools/doctor` runs them all against the real game (also in CI).

- `tools/sad-run up <id> [--save NAME] [--seed N --fixed-step --pause-at N] [--env SAD_BATTLE_AUTOPLAY=1]`: the game in its own run folder, on a virtual display, from a **copy** of `Data/Saves/<NAME>` (default `save1`: its world, seed 7, is generated in the copy on the loading screen, about 5 s; it starts on `w_5_4`; `save2`: another world, seed 42, `w_0_4`; `SAD_SAVE_DIR`, `SAD_SAVE`): a run never writes the saves of the repository; `up` returns once the game plays the save (or is paused). A NAME with no save there is a new game (`--env SAD_WORLD_SEED=N`, else a random seed). `--title`: the title screen (no save given; console `ping` only, no script VM before a save is played; W/S, Return). Ready when the console runs skalang. `tools/sad-run down <id>`, `ps`, `logs <id> --grep ...`.
- `external/ska/tools/ska-console [--run ID] eval '<skalang>'`: in the live game, with `Engine`, `Dev`, `GameDialog`, `Character`, `Map`, `Party`, `Interface`, `Battle`, `Save`, `Bag` imported. Ex: `eval 'Map.name()'`, `eval 'Party.hp(0)'`, `eval 'Engine.setVariable("%00012", 1)'`.
- Agent scripts (`ska-console run <file> args`, `ska-console scripts` lists them): `tools/agent/warp.miniska <map> <x> <y>` (waits for the map; it does not check the block: warped onto a wall (a tree, a cliff), the player cannot move, so pick a walkable block), `battle.miniska <monster id> <level>` (waits for the end; unattended with `SAD_BATTLE_AUTOPLAY=1`: the AI plays both sides, the battle messages close by themselves), `party.miniska`, `variables.miniska [prefix] [all]`; engine: `external/ska/tools/agent/state.miniska`, `entities.miniska <name>...`. They are checked by the build like the game scripts.
- See and act: `ska-console shot <name>` (PNG of the frame), `press <key> [steps]` (map keys: W A S D, Return action, Space jump, 1-4 skills), `pause`, `step N`, `resume`.
- Replay a battle: two runs `--seed 7 --fixed-step --pause-at 120 --env SAD_BATTLE_AUTOPLAY=1`, `run tools/agent/battle.miniska 25 3` then `resume` in each, `ska-run logs <id> --grep "Battle t=" --strip --tail 0`: the traces are identical.
- Web: `tools/web/sad-web up <id> [--env SAD_X=1]` (needs `tools/web/build.sh` and `npm install --prefix tools/web`): the web build in headless Chromium on 127.0.0.1, its own saves; `shot`, `press`, `console`, `eval`, `down`. `tools/web/serve.sh` (it serves the whole network) only when the human asks for it: the harness asks for approval each time.
